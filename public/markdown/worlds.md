**Student Project** 

Infinite Worlds is a procedural generation experiment designed to translate abstract mathematical systems into tangible, interactive environments. By using seeded randomness, the project presents three distinct infinite realms: a boundless recreation of Conway's Game of Life, an aquatic world of ripples and eroding stone, and a drifting sky of Perlin-noise clouds. The core objective was to move beyond raw data, use constraints like tile-based grids to simulate organic phenomena, and express these algorithms as something familiar to us as humans in an immersive way.

On a technical level, the project relies on xxhash to ensure that every coordinate in the infinite plane remains consistent and recreatable. To manage the vast scale of these worlds, I implemented a sparse state management system using JavaScript Map objects and object literals, tracking only rendered tiles and active interactions rather than the entire universe. This was especially crucial for the Game of Life, as it would be computationally impossible to handle every living tile interaction at once. For the water world, I developed a ripple algorithm that calculates Euclidean distance with a "fuzz" variable to render smooth circles on a square grid. In the cloud generator, I mitigated the inherent mirroring issues of Perlin noise by offsetting noise calculations and smoothing the values to achieve a soft, atmospheric density.

One of the project's most effective solutions was changing how the user could visually engage with the infinite grid. In the cloud world, rather than shifting thousands of individual tile coordinates, which would have caused significant performance lag, I implemented a camera-offset system. By locking the sky and cloud data to a stationary grid and moving the camera view, I achieved a scrolling effect that feels like the normal movement of clouds. I also reduced the opacity of cloud tiles near the edges of where the user had cut through, giving the illusion of depth and further adding to the immersion.
